# Python Assignment 2 – Data Structures

## 📌 About the Assignment

This assignment focuses on Python data structures and conditional statements. It covers Lists, Dictionaries, Sets, and If-Else statements.

The purpose of this assignment is to understand how to create, access, modify, and manipulate data structures in Python.

## 🎯 Topics Covered

### 1. Lists
- Creating lists with integer and string elements.
- Adding elements using `append()` and `extend()`.
- Inserting elements using `insert()`.
- Removing elements using `remove()` and `pop()`.
- Sorting lists in descending order.
- Finding maximum, minimum, and sum of list elements.
- Accessing list elements using indexing and slicing.
- Reversing a list.

### 2. Dictionaries
- Creating a dictionary to store student names and marks.
- Accessing values using keys.
- Adding new key-value pairs.
- Updating existing values.
- Using `keys()`, `values()`, and `items()` methods.

### 3. Sets
- Creating sets and understanding unique elements.
- Understanding why duplicate values are removed.
- Learning why sets do not support indexing or item assignment.
- Performing union and intersection operations.

### 4. Conditional Statements
- Using `if`, `elif`, and `else` statements.
- Getting input from the user.
- Validating scores between 0 and 10.
- Categorizing performance as:
  - Above Average
  - Average
  - Below Average
